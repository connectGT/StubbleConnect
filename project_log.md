# StubbleConnect Project Log
**Date**: September 2026
**Event**: Smart India Hackathon (SIH) 2026

## 1. Project Overview
StubbleConnect addresses the critical issue of stubble burning by farmers in North India (Punjab/Haryana). Farmers face a tight 0-5 day window to clear fields for the next crop. StubbleConnect provides a platform that clusters registered farms, matches them with industrial biomass buyers, and optimizes collection logistics before the harvest.

## 2. Tech Stack & Architecture
- **Frontend**: React (Vite), Tailwind CSS v4, `lucide-react` (icons), `react-leaflet` (maps).
- **Backend (Mocked/WIP)**: FastAPI (Python) setup designed for fast asynchronous endpoints.
- **Machine Learning / Intelligence**:
  - `dbscan_cluster.py`: Geospatial clustering of fields based on location and harvest window.
  - `burning_risk.py`: Scoring engine (0-100) determining the likelihood of stubble burning.
  - `vrp_solver.py`: Logistics optimizer using Capacitated Vehicle Routing Problem (CVRP) logic.
- **Infrastructure**: Dockerized (via `docker-compose.yml`) for easy deployment. Monorepo structure (`frontend/`, `backend/`, `ml_engine/`).

## 3. UI/UX Implementation Details

### The Command Center Dashboard
The main dashboard serves as a high-density, real-time logistics view incorporating:
- **Interactive Map**: Built with React-Leaflet to visualize fields, clusters, buyers, and routes.
- **Cluster Details Panel**: Clickable clusters show real-time stats (Tonnage, Harvest Window) and a custom SVG Burning Risk gauge.
- **Stats Row & Widgets**: Live updates of total fields, biomass collected, top buyers, and active routes.
- **Modals**: Reusable modal components for registering fields, adding buyers, and running ML optimizations.

### Role-Based Navigation (Option 1 vs Option 2)
Based on detailed UX research, we implemented a dual-mode Sidebar navigation system:

#### **Option 1: Admin / Operations Mode**
- **Target Audience**: Trained operators, dispatchers, and system administrators.
- **Design Philosophy**: Speed and direct control. 
- **Implementation**: A feature-rich, flat list that exposes advanced workflows (Users, Settings, Quick Actions for routing and AI clustering) directly. All navigation items are one click away.

#### **Option 2: Farmer / Beginner Mode**
- **Target Audience**: Farmers or low-tech literacy users.
- **Design Philosophy**: Progressive disclosure, less noise, simplified cognitive load.
- **Implementation**: A hierarchical, collapsible accordion menu. 
  - Instead of showing all options at once, workflows are grouped (e.g., `Fields > [All Fields, Add Field]`).
  - Expanding one section automatically closes others.
  - Advanced features (like Users and heavy System Settings) are hidden.
  - Language is simplified to focus purely on "Where do I want to go?" (Fields, Buyers, Routes).
